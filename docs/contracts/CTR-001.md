# CTR-001 — Estándar de Diseño Responsive y UX

## Descripción
Define el estándar de diseño responsive y experiencia de usuario para el sitio `voktera.online` y sus futuras landings (verticales y zonas). Garantiza comportamiento consistente en móvil, tablet y escritorio. Documenta el estado **real** del CSS actual (desktop-first) y fija el estándar **deseado** (mobile-first) como objetivo de migración.

## Entradas
- Hoja de estilos compartida `voktera.online/styles.css` (774 líneas), enlazada con `<link rel="stylesheet" href="../styles.css">` en las 15 páginas. No hay CSS embebido en `<style>` (ver CTR-002, checklist obligatorio).
- Variables de diseño: `--bg #F2EFE9`, `--bg-soft #EAE5DB`, `--ink #1F1B16`, `--ink-soft #5A5249`, `--accent #D9651B`, `--accent-2 #4A6B4D`, `--line #D8D2C5`, `--card #FFFFFF`.
- Tipografías: Archivo Expanded (display), Archivo (body), JetBrains Mono (mono).

## Salidas
- Layout adaptable en los breakpoints definidos.
- Comportamiento consistente de navegación, hero, servicios, pasos, zonas y contacto.

## Excepciones
- `prefers-reduced-motion`: desactiva animaciones (`pulse`, `rise`) en hero y toolbox.
- Dispositivos sin soporte de `backdrop-filter`: el nav sticky degrada a fondo sólido.

## API
### Breakpoints reales (estado actual — desktop-first)
Todas las media queries usan `max-width`:

| Breakpoint | Efecto |
|---|---|
| `900px` | `.hero-grid` → 1 columna |
| `800px` | `.steps` → 1 columna |
| `720px` | `.nav-links` se oculta |
| `700px` | `.service-row` → 1 columna |
| `600px` | `.contact` reduce padding a `40px 22px` |

### Estándar deseado (mobile-first)
- Base CSS para móvil; mejoras progresivas con `min-width` en los mismos umbrales (600, 700, 720, 800, 900).
- Targets táctiles ≥ 44px; contraste AA; tipografía fluida con `clamp()` (ya usada en `h1` y `.section-title`).
- Las futuras verticales (MOD-003..006) y zonas (`cerrajero-<ciudad>/`) heredan este estándar.

## API
### Estándar móvil (T-028, vigente)
- **Menú hamburguesa CSS-only** en `max-width: 900px`: `input#nav-toggle.nav-toggle` + `label.nav-burger` (3 span) dentro de `.nav-inner`, seguidos de `<nav class="nav-links">`. El panel se despliega con `.nav-toggle:checked ~ .nav-links` (position:absolute bajo el header, z-index 1000, fondo `--card`). Sin JavaScript.
- **Botón flotante `.wa-float`**: 60x60px en escritorio; `max-width: 600px` → 56x56px, `bottom:20px`, `right:16px`, `z-index:1000`. El footer lleva `padding-bottom:96px` para no quedar tapado.
- **Cobertura**: las 15 páginas (home, 4 verticales, 7 locales, 3 blog) usan el mismo markup y la misma clase; el estilo vive solo en `styles.css`.
- Cualquier página nueva debe heredar estos patrones (ver CTR-002).

## Restricciones
- **No cambiar la paleta ni las variables de diseño** sin consenso (afecta identidad de marca).
- **Deuda técnica declarada:** migrar de `max-width` (desktop-first) a `min-width` (mobile-first) es un cambio de CSS en `index.html`, que tiene tareas activas (T-002, T-004, T-010). No se ejecuta en este contrato; requiere tarea propia y coordinación.
- Los breakpoints pueden añadirse, no eliminarse sin consenso.
