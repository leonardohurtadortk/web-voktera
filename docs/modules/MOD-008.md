# Módulo: Contenidos SEO del blog (docs/seo/)

## 🧭 Cómo trabajar con este módulo
- `adn familia <ruta>` → ver conocimiento vinculado a la ruta.
- `adn arbol <ruta>` → ver jerarquía del módulo.
- `adn crear modulo "..." --scope <ruta>` → crear MOD.
- Si el módulo cuelga de una carpeta padre, asigná `parent: MOD-XXX` para jerarquía.
- `epic_task` referencia la tarea padre principal para agrupar la familia.
- Mantené actualizada la sección "Absorbió conocimiento de" con los artefactos transitorios absorbidos.

## Responsabilidad
Carpeta de borradores Markdown (.md) para los artículos long-tail del blog de Voktera. Es el paso previo al maquetado HTML: aquí vive el texto, las keywords y los enlaces internos sugeridos; NO vive el HTML publicado. Su objetivo es atraer tráfico cualificado al blog y enlazar internamente a las landings de servicio (cerrajería, persianas, muebles, mantenimiento).

Contenido actual (creado en T-027):
- `articulo-3-persiana-atascada.md` — persiana atascada / arreglar cinta persiana. Landing destino: persianas.
- `articulo-4-montar-muebles.md` — montador de muebles a domicilio / precio montar muebles IKEA. Landing destino: muebles.
- `articulo-5-cambiar-bombin.md` — cuándo cambiar el bombín / bombín anti-bumping. Landing destino: cerrajería.

## Componentes principales
No hay código: son documentos Markdown. Cada artículo incluye, por convención de T-027:
- Sección "Palabras clave": principales + long-tail exacto.
- "Respuesta directa": resuelve la intención de búsqueda en el primer párrafo.
- Desarrollo por secciones (causas/riesgos/señales, pasos, cuándo llamar a un técnico).
- "Enlaces internos sugeridos": a qué landing enlazar y con qué ancla.
- CTA a WhatsApp (botón flotante de la web).

## Dependencias
- `voktera.online/blog/` (maquetado HTML por DeepSeek-006, T-023).
- Landings de servicio de `voktera.online/` (cerrajería, persianas, muebles, mantenimiento) como destinos de los enlaces internos.

## Notas
- Los .md son borradores: no publicar HTML ni tocar el blog hasta que el senior coordine el maquetado.
- Tono obligatorio (directriz Claude-001): humano, cercano, transparente; sin frases genéricas de IA ni promesas exageradas.
- Prohibido dar precios inventados: usar rangos honestos y remitir a WhatsApp para precio cerrado.
- Artículo de bombines: no incluir instrucciones de apertura/bypass por seguridad.
- Al crear nuevos artículos, seguir la misma estructura de T-027 y actualizar este MOD.
