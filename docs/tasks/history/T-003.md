## Objetivo
Establecer las bases para la indexación correcta de la web por parte de los buscadores.

## Pasos
1. Crear el archivo `voktera.online/robots.txt` permitiendo el acceso a todo (`User-agent: *`, `Allow: /`) y añadiendo la directiva `Sitemap: https://voktera.online/sitemap.xml`.
2. Crear el archivo `voktera.online/sitemap.xml` con la estructura XML estándar (`<urlset>`, `<url>`, `<loc>`) apuntando solo a `https://voktera.online/` (por ahora).

## Criterios de aceptación
- [ ] `robots.txt` es accesible y apunta al sitemap.
- [ ] `sitemap.xml` tiene formato XML válido y contiene la URL raíz.
