## Objetivo
Invertir las media queries de `.wa-float` y `.blog-content` de `max-width: 600px` a `min-width: 600px`, para que el botón flotante y el blog tengan base móvil y mejora escritorio.

## Pasos
1. Localizar las dos `@media (max-width: 600px)` de `.wa-float` (línea 718) y `.blog-content` (línea 772) de `styles.css`.
2. Base móvil: `.wa-float` 56x56, `bottom:20px`, `right:16px`, `z-index:1000`; `.blog-content` `font-size:1rem`.
3. `@media (min-width: 600px)`: `.wa-float` 60x60, `bottom:24px`, `right:24px`; `.blog-content` `font-size:1.05rem`.
4. Verificar el blog y las páginas con flotante a 375px y 1200px.

## Criterios de aceptación
- [ ] `styles.css` no conserva `max-width: 600px` en `.wa-float` ni en `.blog-content`.
- [ ] A 375px el flotante mide 56x56 y el blog usa `1rem`.
- [ ] A 1200px el flotante mide 60x60 y el blog usa `1.05rem`.
- [ ] El flotante no tapa el footer (padding-bottom:96px se mantiene).
