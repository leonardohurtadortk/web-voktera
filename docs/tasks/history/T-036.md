## Objetivo
Invertir la media query de nav/burger/dropdown de `max-width: 900px` a `min-width: 900px`, de modo que el CSS base describa el móvil y el escritorio sea la mejora progresiva.

## Pasos
1. Localizar el bloque `@media (max-width: 900px)` del nav (líneas 180-214 de `styles.css`).
2. Reordenar: base móvil (`.nav-links` oculto, `.nav-burger` visible, panel desplegable por `.nav-toggle:checked ~ .nav-links`) y `@media (min-width: 900px)` con nav-links horizontal, burger oculto y dropdown en hover.
3. Verificar las 15 páginas a 375px (burger funciona, panel desplegable) y a 1200px (nav horizontal, dropdown hover).
4. Ajustar `z-index` del panel móvil a 1000 para que no quede bajo el header.

## Criterios de aceptación
- [ ] `styles.css` no conserva `max-width: 900px` en nav/burger/dropdown.
- [ ] A 375px el burger es visible y el panel se despliega al marcar el toggle.
- [ ] A 1200px el nav es horizontal, el burger está oculto y el dropdown abre en hover/focus.
- [ ] Las 15 páginas no presentan scroll horizontal a 375px.
