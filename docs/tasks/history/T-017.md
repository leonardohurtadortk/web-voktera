## Objetivo
Mejorar el impacto visual del sitio, integrar imágenes reales de los trabajos y hacer que las tarjetas del toolbox sean interactivas (CRO).

## Pasos
1. **Home (index.html):** 
   - En el Hero, reemplazar el bloque `.toolbox` de la derecha por una imagen de fondo o `<img>` usando `imagenes/equipo-valdemoro.jpg`. Añadir un fallback CSS por si la foto no existe.
   - Hacer que las tarjetas de "lo que resolvemos" en el Hero y en la sección de servicios sean enlaces a WhatsApp (`?text=Hola Voktera, necesito...`) con efecto hover (sombra, elevación, cursor pointer).
2. **Verticales (cerrajeria/index.html, persianas/index.html, etc.):**
   - Añadir una imagen en el Hero de cada una (cerrajería: `imagenes/cerrajeria_valdemoro_001.png`, persianas: `imagenes/persianas_valdemoro_001.png`, muebles y mantenimiento: `imagenes/equipo-valdemoro-002.jpg`).
   - Aplicar el mismo efecto hover interactivo a sus respectivos toolboxes.
3. **Estilos (styles.css):**
   - Añadir las clases necesarias para el efecto hover del toolbox y la estructura de las imágenes en el Hero (que ocupen el 100% del ancho de su columna, con bordes redondeados y sombra).
   - Implementar un fallback visual en caso de que la imagen no cargue (usar un gradiente de fondo y un ícono).

## Criterios de aceptación
- [ ] Las tarjetas del toolbox en la Home abren WhatsApp al hacer clic.
- [ ] Las imágenes del Hero cargan correctamente desde la carpeta `imagenes/`.
- [ ] El CSS tiene un fallback para que el Hero se vea bien incluso si la imagen falta.
- [ ] El diseño se mantiene 100% responsive.
