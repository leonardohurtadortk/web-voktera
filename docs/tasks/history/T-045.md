## Objetivo
Mejorar la tasa de conversión añadiendo el mensaje predefinido contextual (servicio + zona) al botón principal de las 7 páginas locales.

## Pasos
1. En los 7 archivos `voktera.online/cerrajero-<ciudad>/index.html`, buscar el botón del Hero (`class="btn btn-primary"`).
2. Añadir el parámetro `?text=` a la URL de WhatsApp (`https://wa.me/34911266011?text=...`).
3. El texto debe estar codificado (URL encode) e incluir la ciudad. Ejemplo: `Hola%20Voktera%2C%20necesito%20un%20cerrajero%20en%20Valdemoro`.

## Criterios de aceptación
- [ ] Ningún botón Hero de las 7 locales tiene el enlace `wa.me` "pelado" (sin `?text=`).
- [ ] El mensaje incluye el nombre del municipio correspondiente.
