## Objetivo
Crear una página dedicada exclusivamente a cerrajería para mejorar el SEO y la conversión.

## Pasos
1. Extraer el bloque `<style>` de `voktera.online/index.html` a un archivo `voktera.online/styles.css` y enlazarlo desde el HTML para no duplicar código.
2. Crear `voktera.online/cerrajeria/index.html` reutilizando la estructura general pero adaptando el H1, meta tags, copy y JSON-LD específicamente para "Cerrajería en el Sur de Madrid".

## Criterios de aceptación
- [ ] El archivo CSS externo se carga correctamente en la home y en la nueva landing.
- [ ] La landing tiene contenido específico sobre cerrajería y metadatos únicos.
