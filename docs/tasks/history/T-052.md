## Pasos
1. Insertar el bloque gtag.js (`<script async src="...gtag/js?id=G-4NT56D8Y7Q">` + inicialización `gtag('config','G-4NT56D8Y7Q')`) justo antes de `</head>` en las 15 páginas (home + 3 blogs + 4 verticales + 7 locales).
2. Verificar que el ID aparece exactamente 2 veces por página (script src + config), sin duplicados.
