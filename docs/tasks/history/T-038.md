## Objetivo
Invertir la media query de `.toolbox-grid` de `max-width: 600px` a `min-width: 600px`, para que el toolbox de 4 servicios sea 1 columna en móvil y 2x2 en escritorio.

## Pasos
1. Localizar `@media (max-width: 600px){ .toolbox-grid{ grid-template-columns:1fr; } }` (línea 438 de `styles.css`).
2. Base móvil: `.toolbox-grid` una columna.
3. `@media (min-width: 600px)`: `.toolbox-grid` dos columnas (`1fr 1fr`).
4. Verificar home y verticales a 375px (1 columna) y 1200px (2x2).

## Criterios de aceptación
- [ ] `styles.css` no conserva `max-width: 600px` en `.toolbox-grid`.
- [ ] A 375px el toolbox muestra 1 tarjeta por fila.
- [ ] A 1200px el toolbox muestra 2x2.
- [ ] Las 4 tarjetas conservan icono, título y descripción en ambos tamaños.
