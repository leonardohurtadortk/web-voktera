## Objetivo
Añadir metadatos esenciales en `voktera.online/index.html` para que Google e IAs entiendan la entidad del negocio y redes sociales muestren previews correctos.

## Pasos
1. En el `<head>`, insertar el script `application/ld+json` con el schema `LocalBusiness`. Debe incluir horario (L-S 8:00-22:00, Dom cerrado), teléfono (+34911266011) y AreaServed (Valdemoro, Parla, Getafe, Leganés, Pinto, Fuenlabrada, Rivas-Vaciamadrid).
2. Añadir la etiqueta `<link rel="canonical" href="https://voktera.online/">`.
3. Añadir las etiquetas Open Graph (`og:title`, `og:description`, `og:image`, `og:url`, `og:type`).
4. Añadir las etiquetas Twitter Card (`twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`).

## Criterios de aceptación
- [ ] El código HTML pasa la validación de Schema.org sin errores.
- [ ] Los metadatos OG y Twitter apuntan a la URL real y al título correcto.
