## Objetivo
Invertir la media query de `.contact` de `max-width: 600px` a `min-width: 600px`, para que el bloque de contacto tenga padding móvil por defecto y padding amplio en escritorio.

## Pasos
1. Localizar `@media (max-width: 600px){ .contact{ padding:40px 22px; } }` (línea 622 de `styles.css`).
2. Base móvil: `.contact` padding `40px 22px`.
3. `@media (min-width: 600px)`: `.contact` padding `56px 40px`.
4. Verificar el bloque de contacto a 375px y 1200px.

## Criterios de aceptación
- [ ] `styles.css` no conserva `max-width: 600px` en `.contact`.
- [ ] A 375px el padding es `40px 22px` y el texto no se corta.
- [ ] A 1200px el padding es `56px 40px`.
- [ ] Los botones del contacto siguen centrados y sin desborde en ambos tamaños.
