## Objetivo
Crear la página índice del blog siguiendo el estándar del CTR-002 y añadir el enlace en el menú de navegación de la Home.

## Pasos
1. Crear la carpeta `voktera.online/blog/` y dentro un `index.html` que herede el CSS (`../styles.css`) y la estructura (nav, footer) de la web principal.
2. En el `<body>`, crear un grid o lista que muestre las tarjetas de los artículos (inicialmente vacío o con placeholders).
3. Modificar el `<nav>` de `voktera.online/index.html` para añadir un enlace a `blog/index.html` (ej. "Consejos").

## Criterios de aceptación
- [ ] El archivo `/blog/index.html` es accesible y carga `styles.css`.
- [ ] El menú de la Home tiene un enlace funcional a `/blog/`.
